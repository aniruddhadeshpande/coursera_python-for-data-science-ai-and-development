
### **Tuples**

* Used in Python to group related data together.
* Tuples are **ordered and immutable** collections of elements.
* Written as **comma-separated elements** inside **parentheses `()`**.
* Can contain **strings, integers, floats**, and other data types.
* Support **positive and negative indexing** for element access.
* Operations such as **combining, concatenating, and slicing** can be performed.
* Because they are **immutable**, modifying a tuple requires creating a **new tuple**.
* Tuples can be **nested** (contain other tuples or complex data types).
* Elements in a **nested tuple** are accessed using **multiple indices**.

---

### **Lists**

* Lists are **ordered collections** of items that are **mutable**.
* Represented using **square brackets `[]`**.
* Can store **different data types** (strings, integers, floats, etc.).
* Lists **support nesting** (lists within lists).
* Elements can be accessed using **positive and negative indexing**.
* Modifying operations (**concatenation, append**) change the **same list**.
* Support operations like **adding, deleting, splitting**, and more.
* Elements are separated using **delimiters (commas)**.
* **Aliasing** occurs when multiple names refer to the **same list object**.
* Lists can be **cloned** to create **independent copies**.

---

### **Dictionaries**

* Dictionaries store **key–value pairs**, allowing flexible and fast data lookup.
* Both **keys and values** can be strings or other data types.
* Represented using **curly brackets `{}`**.
* **Keys must be immutable and unique**.
* **Values can be mutable or immutable**, and duplicate values are allowed.
* Key–value pairs are separated by **commas**.
* Can be **assigned to a variable**.
* A **key** is used to retrieve its **corresponding value**.
* Support **adding and deleting** key–value pairs.
* Checking for a key returns a **Boolean value** (`True`/`False`).
* Methods exist to get **lists of keys and values**.

---

### **Sets**

* Sets are **collections of unique elements**, useful for **removing duplicates** and performing set operations.
* Represented using **curly brackets `{}`**.
* **Do not allow duplicate items**.
* Converting a **list to a set** removes duplicates.
* Support **Set Operations** such as **add, remove, and membership checking**.
* Sets can be combined using **`&` (intersection)** to get **common elements**.
* The **union operation** returns all elements from both sets (unique + common).
* The **subset method** checks if one set is a **subset of another**.
* Sets are **unordered**.
