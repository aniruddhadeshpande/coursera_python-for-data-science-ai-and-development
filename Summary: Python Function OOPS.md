### **✅ Python Conditions & Comparisons**

* Python uses `if` statements to run code based on **True/False** conditions created by comparisons and Boolean expressions.
* Comparison operations use operators such as `==` (equal to), `>` (greater than), and `<` (less than).
* The `!=` operator checks whether two values are **not equal**.
* Integers, strings, and floats can be compared.

---

### **✅ Branching (Decision Making)**

* Python uses conditional statements (`if`, `elif`, `else`) to direct program flow and execute different code blocks.
* `if` defines actions to execute when a condition is **True**.
* `else` runs when **all previous conditions are False**.
* `elif` allows **additional condition checks** when the first `if` is False.
* Boolean logic operators execute operations on Boolean values.

---

### **✅ Loops**

* Loops automate **repetitive tasks** and iterate over data structures such as lists and dictionaries.
* `range()` generates a sequence of numbers with defined start, stop, and step values.
* `for` loops iterate over sequences (lists, tuples, strings, etc.).
* `while` loops run as long as a specified condition remains **True**.

---

### **✅ Functions**

* Functions are **reusable code blocks** that perform tasks, accept inputs, and often return results—supporting modular and reusable programming.
* Python includes built-in functions like:

  * `len()` → gets the length of a sequence
  * `sum()` → calculates the total of elements
  * `sorted()` → returns a new sorted list
  * `.sort()` → sorts the original list
* You can also **create your own functions**.
* Functions should include a **docstring** (triple-quoted string) for clarity and maintainability.
* The `help()` command displays a function’s documentation.
* A function can have **multiple parameters**.
* If a function has no `return` statement, it returns **`None`** by default.
* The `pass` keyword defines an **empty placeholder function**.
* Functions often perform **multiple tasks**.

---

### **✅ Variable Scope**

* Variable scope determines where a variable can be accessed or modified.
* **Local variables** exist only inside a function/block.
* **Global variables** are defined at the top level and can be accessed anywhere in the program.

---

### **✅ Exception Handling**

* Exception handling prevents programs from crashing due to errors.
* `try-except` handles exceptions and defines alternative behavior when errors occur.
* `try-except-else` adds code to run **only when no exceptions occur**.
* `try-except-else-finally` ensures the `finally` block **always runs**, regardless of exceptions.

---

### **✅ Objects & Classes (OOP)**

* Objects are **instances of classes**, containing data and behavior.
* The `type()` function checks an object’s type.
* Methods may change an object’s internal state, but its **type remains the same**.
* Classes act as **blueprints** for creating objects, defining attributes and methods.
* `__init__` is a **special method** that initializes object attributes.
* You can create **instances (objects)** from a class.
* **Data attributes** store object data.
* **Methods** are functions inside classes that interact with or modify data attributes.
* Methods require `self` as the first parameter (along with others if needed).
